# BroodjesApp feedback

Dit is het openbare meldpunt voor fouten, wensen en ideeen voor de BroodjesApp.
Deze repository bevat geen broncode.

## Een melding maken

[Maak een issue aan](https://github.com/KoenKPI/broodjes-app-feedback/issues/new).
Je hebt hiervoor een GitHub-account nodig.

Beschrijf wat je probeerde, wat er gebeurde en wat je verwachtte.
Vermeld bij een fout hoe deze te herhalen is en welke browser je gebruikt.
Controleer eerst of er al een vergelijkbare melding bestaat.

## Let op: alles is openbaar

Issues, reacties en bijlagen zijn voor iedereen zichtbaar.
Plaats geen wachtwoorden, tokens, persoonsgegevens, interne adressen of
vertrouwelijke bedrijfsgegevens. Verwijder deze ook uit screenshots.
Meld beveiligingsproblemen niet als openbaar issue, maar rechtstreeks bij de
appbeheerder via het gebruikelijke interne kanaal.

De broncode en het oplossen van meldingen worden afzonderlijk en prive beheerd.
